# Solution: Azure AI Foundry Portal Environment & Ingestion

Deployment of embedding pipelines (`text-embedding-ada-002`) and validation of RAG (Retrieval-Augmented Generation) capabilities inside the Chat Playground using Margie's Travel brochures.

The `gpt-4o` deployment was successfully grounded using the generated index inside the Azure AI Foundry Playground. The retrieval mechanics were validated against static data inside the source PDFs.
