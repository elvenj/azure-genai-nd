# Udacity Azure Generative AI Engineer
This repository contains labs, projects, and technical notes for the Udacity Nanodegree program.

## Project Structure
- **/labs**: Lesson exercises and API connection tests.
- **/projects**: Capstone and course projects.
- **/data**: Datasets and documents for RAG (git-ignored).
- **/notes**: Personal study notes and architecture diagrams.

## Setup Instructions
1. Activate the environment: `source venv/bin/activate`
2. Install dependencies: `pip install -r requirements.txt`
3. Configure your `.env` file with your Azure OpenAI credentials.
